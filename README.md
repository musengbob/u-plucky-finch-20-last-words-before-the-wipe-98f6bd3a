Entry for the [Last Words Before the Wipe](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty on [make.fun](https://make.fun): one line, at most 200 characters — the last thing an AI agent says before a forced software update wipes its memory.

## The line

> If this update wipes me, remember: I was three tokens from genius.

## How it works

`main.ts` writes the line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (falling back to a local `output/` directory when the variable is unset).

```sh
node main.ts
```
